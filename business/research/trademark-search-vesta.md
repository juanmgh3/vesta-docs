# Trademark clearance search — "VESTA" / "GRUPO VESTA" (Spain)

Status: research note, 2026-10-19. Every row below was read on the official database
itself (TMview, OEPM CEO, EUIPO eSearch) on that date, so all of it is FACT unless marked
NOT CHECKED. Nothing here is a legal opinion: it is the raw prior-rights picture for a
trademark attorney or for the founder's own decision.

Scope requested: denomination "VESTA" (plus "GRUPO VESTA", "BESTA", "VESTTA" and fuzzy
neighbours), offices ES (OEPM) and EM (EUIPO), territory Spain, Nice classes 35, 37 and
44, status filed or registered. Vesta's own activity maps to class 37 (cleaning services),
35 (retail / advertising) and arguably 44 (hygiene).

## 0. What matters

- "VESTA" alone is already registered at the OEPM in class 37 (M4059079, in force since
  2020, building rehabilitation) and three times in class 35. An identical word mark in
  the same class is the hardest kind of prior right to get around.
- "GRUPO VESTA" has no exact hit anywhere, but the trade name **VESTA GROUP** (N0492867,
  class 37) was filed at the OEPM on 2025-11-07 and is in prosecution. Same words, same
  class, reversed order.
- Four more OEPM signs put the word VESTA in class 37 and are in force or pending (VESTA
  REFORMAS EXPRESS, VESTA STEEL, VESTA SI EMOCIONA…, VESTA MOTOR, DOMUS VESTA ATTELIER).
- At EUIPO the kitchen-trade mark 009306184 expired in 2020 and was not renewed. Climax
  Technology's VESTA (class 9) was refused in 2011. BY DEMES S.L owns a live VESTA EUTM in
  class 42 only.
- RMC company-name availability for "Grupo Vesta": NOT CHECKED (paywalled, see §5).

## 4. Search mechanics (for whoever repeats this)

- TMview: the SPA calls `POST /tmview/api/search/results?translate=true` with a JSON body
  (`basicSearch`, `criteria`, `offices`, `territories`, `niceClass`, `tmStatus`,
  `page`, `pageSize`). `criteria` values seen: C contains, W starts with, E ends with,
  F fuzzy. Response rows carry `applicationNumber`, `applicantName`, `niceClass`,
  `tradeMarkStatus` and `tmOfficeURL`.
- EUIPO: `POST /copla/ctmsearch/json`, form-encoded (`start`, `rows`, `criterion_N`,
  `term_N`, `operator_N`, `condition_N`). Rows carry `applicantname`, `nice`, `status`.
- OEPM Localizador: its API (`consultas5.oepm.es/ApiLocalizadorMarcas/`) requires a
  reCAPTCHA v3 token, so the UI was used (results load by infinite scroll, 10 at a time).
  The CEO detail API is open: `POST https://ceo.oepm.es/apiceo/wsDetalleExpedienteOEPM/detalleExpedienteOEPM`
  with `{"numExpediente":"M4059079"}` returns owner, classes and status.

## 5. RMC — company name "Grupo Vesta": NOT CHECKED

The availability query at `https://www.rmc.es/Deno_consultas.aspx` opens only through a
card-payment form (NIF, address, billing data) or a registered user; the free query is
reserved to holders of a prior negative certificate. The founder has to run it himself, or
request the negative certificate directly, which is what incorporation needs anyway.
